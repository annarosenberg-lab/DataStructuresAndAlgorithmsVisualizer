# Algorithm Learning App

A desktop-first responsive web app for interview algorithm review.

## Stack
- React (via Next.js App Router)
- Node.js runtime
- TypeScript

## Features in MVP
- Clean dashboard with square topic widgets
- Topic pages for:
  - Binary Search
  - Linear Search
  - Bubble Sort
  - Merge Sort
- Static visual previews on each dashboard widget
- Auto-play algorithm visualization
- Replay button for animations
- Syntax-highlighted Python code
- Time complexity summary + explanation

## Run locally
1. Install dependencies:
   ```bash
   npm install
   ```
2. Start dev server:
   ```bash
   npm run dev
   ```
3. Open:
   [http://localhost:3000](http://localhost:3000)

## Build for production
```bash
npm run build
npm run start
```
